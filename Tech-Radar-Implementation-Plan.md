# Tech Radar — Implementation Plan

This repository implements the attached plan: a static architecture knowledge viewer backed by Git, with structured YAML content, deterministic compilation to `content.json`, a React UI, and an nginx runtime image.

The full product decisions are recorded in the original project brief. The implementation keeps V1 deliberately focused: no backend, authentication, database, Markdown rendering, raw HTML rendering, GUI editing, trade-off catalog, or custom ring semantics.
